# 정부 안내서비스 검색 제출물

## 배포 URL

https://여기에-Netlify-주소-입력.netlify.app

## 구현 기능

- 24건 정부 안내서비스 목록 표시
- 서비스명 검색
- 안내분야 필터
- 결과 건수 표시
- 반응형 화면 지원

## AI 활용 메모

생성형 AI를 활용하여 HTML, CSS, JavaScript 기반의 정적 웹페이지를 제작하였다.
안내서비스_목록.json 데이터를 읽어 카드 형태로 출력하며,
서비스명 검색, 안내분야 필터, 결과 건수 표시 기능을 구현하였다.

## 테스트 결과

- 초기 접속 시 결과 24건 표시
- 서비스명 검색 정상
- 안내분야 필터 정상
- 건수 표시 정상
