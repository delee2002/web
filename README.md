# 인사교류 및 채용제도 개선 보도자료 페이지

## 포함 파일
- `index.html`: 보도자료 본문
- `style.css`: 반응형 디자인

## GitHub Pages 배포
1. 새 GitHub 저장소를 만듭니다.
2. 압축을 푼 뒤 `index.html`과 `style.css`를 저장소 최상위 경로에 업로드합니다.
3. 저장소의 **Settings > Pages**로 이동합니다.
4. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 **Save**를 누릅니다.

별도 빌드 도구나 외부 라이브러리가 필요 없는 정적 페이지입니다.
