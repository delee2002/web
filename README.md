# 2026 안전점검 보고서 정적 웹페이지

## 구성 파일
- index.html: 페이지 구조
- style.css: 반응형 및 접근성 스타일
- app.js: JSON 로드, 검색 필터, 결과 수 표시
- 장데이터.json: 보고서 5개 장 데이터
- netlify.toml: Netlify 게시 경로와 기본 응답 헤더

## Netlify 배포
1. ZIP 파일의 압축을 풉니다.
2. Netlify 대시보드의 수동 배포 영역에 압축을 푼 폴더 전체를 드래그합니다.
3. 배포 후 생성된 사이트에서 첫 화면에 5개 카드가 표시되는지 확인합니다.
4. 검색창에 `예산`을 입력해 관련 카드만 남고 결과 수가 바뀌는지 확인합니다.

## 주의
index.html을 파일 탐색기에서 직접 열면 브라우저의 로컬 파일 보안 정책 때문에 JSON 읽기가 차단될 수 있습니다. Netlify에 배포하거나 로컬 HTTP 서버에서 확인하세요.
